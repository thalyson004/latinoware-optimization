# Latinoware Optimization Examples

Exemplos executáveis para a palestra **Como Formular e Resolver Problemas Complexos** (Latinoware 2026).

Os exemplos acompanham o ciclo da palestra: formulação linear de uma dieta ilustrativa, teste de viabilidade, relaxamento linear, modelo inteiro e heurística. Valores nutricionais e custos dos exemplos são sintéticos e didáticos; não são recomendação alimentar nem dados de mercado.

## Ambiente

Python 3.10 ou superior. Instruções de instalação e execução serão adicionadas junto aos exemplos.
